SUPREME SEED - Android APK Build Project

এই প্রকল্পে আপনার আপলোড করা Four_Regions_Pabna_Search_Updated_Netlify.zip-এর মূল index.html এবং সব asset অপরিবর্তিত রাখা হয়েছে।

APK তৈরির ধাপ (কম্পিউটারে):
1. ZIP Extract করুন।
2. Android Studio খুলুন > Open > SupremeSeed_Android_Project_OriginalDesign ফোল্ডার নির্বাচন করুন।
3. Gradle Sync সম্পন্ন করুন। প্রয়োজন হলে Android SDK 35 ও JDK 17 ইনস্টল করুন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s)।
5. APK পাওয়া যাবে app/build/outputs/apk/debug/app-debug.apk ফাইলে।
6. ফোনে APK কপি করে Install করুন (প্রয়োজনে Install unknown apps অনুমতি দিন)।

নোট: এটি Android Studio সোর্স প্রজেক্ট, তৈরি APK নয়। মূল চারটি রিজিওনের ছবি ও JPG কোড অপরিবর্তিত আছে। Stock Report ও Depot Demand মূল সোর্সে না থাকলে এই প্যাকেজে নতুন করে যোগ হয়নি। JPG সংরক্ষণ ও অন্যান্য ফিচার APK-তে আলাদাভাবে পরীক্ষা করতে হবে।
